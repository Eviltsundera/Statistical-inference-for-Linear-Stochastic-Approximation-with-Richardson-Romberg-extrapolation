# Статья для PSTA

Это отдельный проект статьи для журнала «Программные системы: теория и
приложения». Исходники диплома в корне репозитория не перемещались.

## Состав

- `main.tex` — входной файл рукописи; русские и английские
  метаданные находятся в его преамбуле, как в официальном шаблоне `psta`;
- `definitions.tex` — общие обозначения и математические макросы;
- `rr_gaussian.tex` — основной результат для RR+PR и его доказательство;
- `discussion.tex` — ограничения и заключение;
- `psta.cls`, `psta/` — официальный стиль из `psta.zip` от 17 марта 2026 года;
- `figures/rr_main_experiment.pdf` — векторный двухпанельный рисунок;
- `figures/plot_rr_main_experiment.py` — его сборка из сохранённых CSV;
- `main.pdf` — актуальная проверенная 19-страничная blind-сборка A5;
- `SOURCE_MAP.md` — происхождение теории и численных результатов;
- `SUBMISSION_CHECKLIST.md` — действия, требующие решения автора.

## Сборка

Из каталога `article-psta` выполнить два прохода:

```sh
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

На рабочей машине, где TeX Live перенесён в домашний каталог, до исправления
системной символической ссылки следует задать его фактический корень:

```sh
export TEXMFROOT=/home/levenson/texlive/texlive
export TEXMFCNF="$TEXMFROOT/texmf-dist/web2c:/etc/texmf/web2c"
```

Рисунок при необходимости пересобирается из корня репозитория в окружении
проекта:

```sh
cd code
uv run python ../article-psta/figures/plot_rr_main_experiment.py
```

## Анонимная сборка

`main.tex` собирается со штатной опцией `blind`. При формировании колонтитулов
обе текстовые метки передаются пустыми; вверху страниц остаются только
расположенные по шаблону номера. Файл класса `psta.cls` не изменяется. Макрос
`\AfterPeer` исключает из PDF публичную ссылку на код. Сам исходник `main.tex`
и `SOURCE_MAP.md` содержат идентифицирующие сведения, поэтому blind ZIP также
требует очищенной копии; подробности перечислены в checklist.

## Объём и стиль

Текущий blind-макет занимает 19 страниц A5. На сайте журнала формального лимита
страниц нет; ориентир 15 страниц является внутренним пожеланием.

В классе `psta` версии 2026-03-17 поля `\arxiv` и `\paperid` сохраняются, но
не выводятся. Поэтому библиографические записи используют видимые ссылки через
`\miscnote`.
