# Статья для PSTA

Это отдельный проект статьи для журнала «Программные системы: теория и
приложения». Исходники диплома в корне репозитория не перемещались и не
изменялись.

## Состав

- `main.tex` — анонимная рукопись в официальном классе `psta`;
- `metadata.tex` — русские и английские метаданные;
- `psta.cls`, `psta/` — официальный стиль из `psta.zip`, версия от
  17 марта 2026 года;
- `figures/rr_main_experiment.pdf` — главный двухпанельный эксперимент;
- `figures/plot_rr_main_experiment.py` — его воспроизводимая сборка из
  сохранённых CSV без повторного запуска моделирования;
- `main.pdf` — проверенная 13-страничная сборка в формате A5;
- `SOURCE_MAP.md` — происхождение теории и численных результатов;
- `SUBMISSION_CHECKLIST.md` — что нужно заполнить перед отправкой.

## Сборка

Официальный способ:

```sh
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Рисунок главного эксперимента при необходимости пересобирается из корня
репозитория командой
`python3 article-psta/figures/plot_rr_main_experiment.py`.

Файл собирается с опцией `blind`: сведения об авторе не выводятся в PDF для
двойного слепого рецензирования. После рецензирования нужно убрать `blind` из
первой строки `main.tex`, заполнить авторские поля и добавить фотографию.

Цель по объёму — не более 15 страниц готового A5-макета, включая английскую
титульную часть и литературу. На сайте журнала формального лимита 15 страниц
нет; это рабочее ограничение научного руководителя.

В классе `psta` версии 2026-03-17 поля `\arxiv` и `\paperid` сохраняются, но
не выводятся. Поэтому две записи в списке литературы используют видимый обход
через `\miscnote` с `\href`/`\doi`; до обновления класса его лучше сохранить.

Официальные требования:
<https://psta.psiras.ru/publ-conditions/publ-conditions.html>.
