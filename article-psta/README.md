# Статья для PSTA

Это отдельный проект статьи для журнала «Программные системы: теория и
приложения». Исходники диплома в корне репозитория не перемещались.

## Состав

- `main.tex` — входной файл анонимной рукописи в официальном классе `psta`;
- `metadata.tex` — русские и английские метаданные;
- `rr_gaussian.tex` — основной результат для RR+PR и его доказательство;
- `discussion.tex` — ограничения и заключение;
- `psta.cls`, `psta/` — официальный стиль из `psta.zip` от 17 марта 2026 года;
- `figures/rr_main_experiment.pdf` — векторный двухпанельный рисунок;
- `figures/plot_rr_main_experiment.py` — его сборка из сохранённых CSV;
- `main.pdf` — актуальная проверенная 23-страничная сборка A5;
- `SOURCE_MAP.md` — происхождение теории и численных результатов;
- `SUBMISSION_CHECKLIST.md` — действия, требующие решения автора.

## Сборка

Из каталога `article-psta` выполнить два прохода:

```sh
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Рисунок при необходимости пересобирается из корня репозитория в окружении
проекта:

```sh
cd code
uv run python ../article-psta/figures/plot_rr_main_experiment.py
```

## Анонимная подача

Файл собирается с опцией `blind`. Макрос `\AfterPeer` действительно исключает
публичную ссылку на код из reviewer PDF; официальный `\HideFromPeer` для этого
не подходит, поскольку лишь визуально помечает аргумент. Сам исходник
`metadata.tex` и `SOURCE_MAP.md` содержат идентифицирующие сведения, поэтому в
blind ZIP нужна их очищенная копия; подробности перечислены в checklist.
После рецензирования следует убрать `blind`, заполнить авторские поля и добавить
фотографию.

## Объём и стиль

Текущий макет занимает 23 страницы A5. На сайте журнала формального лимита
страниц нет; ориентир 15 страниц является внутренним пожеланием и потребует
отдельного согласования или содержательного сокращения.

В классе `psta` версии 2026-03-17 поля `\arxiv` и `\paperid` сохраняются, но
не выводятся. Поэтому библиографические записи используют видимые ссылки через
`\miscnote`.

Официальные требования:
<https://psta.psiras.ru/publ-conditions/publ-conditions.html>.
