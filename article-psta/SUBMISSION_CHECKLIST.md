# Что заполнить перед подачей

- [ ] Согласовать с научным руководителем название и состав авторов.
- [ ] Заполнить email, ORCID, 4–7 строк биографии и CRediT-вклад каждого
  автора в преамбуле `main.tex`.
- [ ] Отметить автора для переписки командой `\correspondent` сразу после
  его email.
- [ ] Добавить качественные фотографии авторов в `pics/`.
- [ ] Подтвердить у редакции или библиографа предварительный УДК
  `519.245:519.217.2`; MSC 2020 сейчас `62L20; 60J20, 65C40`.
- [ ] Подтвердить рубрику 7 «Методы оптимизации и теория управления».
- [ ] Указать финансирование, благодарности и конфликт интересов либо их
  отсутствие.
- [ ] Ещё раз проверить библиографические метаданные и DOI.
- [ ] Решить, нужно ли включать научного руководителя как соавтора; это нельзя
  предполагать автоматически.
- [x] Reviewer PDF собирается со штатной опцией `blind`; текстовые метки
  колонтитулов очищены, поэтому вверху остаются только номера страниц.
  Макрос `\AfterPeer` очищает только PDF, поэтому для исходников подготовить отдельный архив с
  анонимизированным `main.tex`, без `SOURCE_MAP.md`, публичной GitHub-ссылки,
  ФИО, аффилиаций, финансирования и благодарностей. В финальной версии убрать
  опцию `blind` и вернуть эти сведения.
- [x] Русская и английская аннотации имеют 100--250 слов; каждый список
  содержит 3--15 ключевых слов/словосочетаний.
- [ ] Включить в ZIP все используемые исходники: `main.tex`,
  `rr_gaussian.tex`, `discussion.tex`, официальный класс,
  каталог `psta/` и векторные рисунки; не включать `*.aux`, `*.log`,
  `*.out`, `*.orig` и `*.rej`.
- [x] После сокращения теории дважды собрать
  `pdflatex -interaction=nonstopmode -halt-on-error main.tex` с официальным
  классом ПСТА от 17.03.2026 и устранить undefined references, citations и
  overfull boxes.
- [x] В текст добавлены генератор задач, seeds, полная сетка горизонтов и
  точные NBM/OBM-формулы; публичный commit кода и данных зафиксирован.
- [ ] Для blind-подачи приложить анонимизированную копию кода и данных без
  истории Git и заменить идентифицирующую публичную ссылку.
- [ ] Согласовать с научным руководителем объём итоговой версии. У журнала
  формального лимита страниц нет, но внутренний ориентир равен 15 страницам.
- [ ] Подготовить авторскую справку и согласие на обработку персональных данных
  по образцам журнала.
- [ ] Отправить ZIP на `info@psta.psiras.ru`; в письме подтвердить согласие с
  порядком публикации и готовность предоставить требуемые формы.
